# space_shooter
Простая игра (Space Shooter) на Python\
Правила игры: уничтожить 5 инопланетных корабля и сохранить целостность своего\
Управление: 
* Space - выстрел 
* Стрелки (направления: право и лево) - перемещение

Готовый файл можно скачать как архив, зайдя в раздел Releases\
Папка Media необходима для корректной работы игры
